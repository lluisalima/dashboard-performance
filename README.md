# 📋 Painel da Equipe — Montadora

Dashboard web simples e acessível para gestão de presença, tarefas e desempenho de colaboradores.

## Como usar

1. Abra `index.html` no navegador
2. Toque nos botões para marcar presença ou concluir tarefas
3. Os cartões e o gráfico atualizam automaticamente

## Tecnologias

- HTML5 semântico
- CSS3 (acessibilidade: fontes grandes, alto contraste)
- JavaScript vanilla (sem frameworks)
- Chart.js para gráficos

## Estrutura

```
painel-equipe/
├── index.html    # estrutura da página
├── style.css     # estilos e acessibilidade
└── script.js     # lógica e dados
```
